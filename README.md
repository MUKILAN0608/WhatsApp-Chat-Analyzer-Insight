# 📱 WhatsApp Chat Analyzer Insight

**WhatsApp Chat Analyzer Insight** is a powerful analytics tool that transforms your exported WhatsApp chat data into insightful visualizations and metrics. Dive deep into your conversations with features like message trends, sentiment analysis, emoji usage, response time analysis, and social network graphs — all within an interactive, easy-to-use Streamlit app.

---

## 🚀 Features

- 📊 **Message & Word Count**: Get detailed counts of messages and words for individual users or the entire chat.
- 😊 **Emoji Analysis**: Discover the most frequently used emojis and their distribution across participants.
- 🧠 **Sentiment Analysis**: Analyze the overall sentiment (positive, negative, neutral) of your conversations.
- ⏱️ **Response Time Analysis**: Measure the average response times for each chat participant.
- 🌐 **Interaction Network**: Visualize the social interaction graph of your chat group.
- 📅 **Timeline Visualizations**: Track activity trends over time with daily and monthly activity charts.
- 🔗 **Link and Media Analysis**: Monitor the number of shared links and media files within the conversation.

## 📥 Installation

Run the following commands in your terminal to set up and launch the application:

# Step 1: Clone the repository
git clone https://github.com/MUKILAN0608/whatsapp-chat-analyzer-insight.git

# Step 2: Navigate to the project directory
cd whatsapp-chat-analyzer-insight

# Step 3: Install the required dependencies
pip install -r requirements.txt

# Step 4: Launch the Streamlit application
streamlit run app.py

📖 Usage
Export a WhatsApp chat in .txt format.

Open the application using Streamlit.

Upload the exported chat file via the app interface.

Select a specific user or analyze the entire group chat.

Explore a range of visualizations, insights, and statistics derived from your chat data.
