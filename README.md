# 📱 WhatsApp Chat Analyzer Insight

**WhatsApp Chat Analyzer Insight** is a professional-grade analytics tool designed to convert your exported WhatsApp chat data into insightful, interactive visualizations. Built with **Streamlit**, this application empowers users to uncover message trends, sentiment patterns, emoji usage statistics, response time metrics, and social interaction networks — all through an intuitive, user-friendly interface.

---

## 🚀 Key Features

- 📊 **Message & Word Count Analysis**  
  Gain a clear breakdown of the total number of messages and words exchanged by each participant in the chat.

- 😊 **Emoji Usage Insights**  
  Identify the most frequently used emojis and their distribution across participants.

- 🧠 **Sentiment Analysis**  
  Classify messages into **positive**, **negative**, or **neutral** categories using a fine-tuned Natural Language Processing (NLP) model.

- ⏱️ **Response Time Metrics**  
  Calculate and visualize average response times for each participant, offering insights into conversation dynamics.

- 🌐 **Interaction Network Graph**  
  Visualize social connections and interaction patterns using dynamic network graphs.

- 📅 **Timeline & Activity Charts**  
  Track message activity trends over **days**, **months**, or custom time periods with comprehensive timeline charts.

- 🔗 **Link & Media Tracking**  
  Monitor the number and types of URLs and media files shared within the conversation.

---

## 📖 How to Use
Export your WhatsApp chat as a .txt file (without media).

Upload the exported file via the Streamlit web interface.

Choose to analyze either a specific participant or the entire group chat.

Explore rich visualizations, detailed metrics, and actionable insights across multiple analysis modules.
